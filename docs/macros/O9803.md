# O9803 — Set SAFE_Z_MACHINE (No Motion)

## Purpose
Store the machine-coordinate safe Z clearance plane in persistent variables. This macro performs **no axis motion** and **uses no M-codes**.

## Preconditions (Required machine state)
- Spindle state: Any (no spindle commands issued).
- Coolant state: Any (no coolant commands issued).
- Modal requirements (G90/G94/G40/G80 etc.): None (no G-codes used).
- SAFE_Z_MACHINE must be set: **This macro sets it**.

## Inputs (Macro arguments)
- `A` = `SAFE_Z_MACHINE_IN` (inches, machine coordinate). **Required.**

## Outputs
- Variables written (local/common/persistent):
  - `#526` SAFE_Z_MACHINE_IN
  - `#527` SAFE_Z_MACHINE_MM (computed from inches)
  - `#585` LAST_STATUS = `1`
- Offsets written (WCS/tool offsets), if any: None.
- Logs updated (#580–#599): `#585`.

## Safety checks and failure modes
- If `A` is missing or `0`, the macro raises a **hard alarm** via `#3000` and does not write variables.
- Optional operator confirmation message via `#3006` when `#501 != 0`.

## Step-by-step flow (operator/comprehension view)
1) Validate input `A` is non-zero.
2) Store `A` to `#526` and compute `#527 = #526 * 25.4`.
3) Set `#585 = 1`.
4) If verbose, display a confirmation message.

## G/M code explainer (every code used)
- **None.** This macro does not issue G-codes or M-codes.
- System variables used:
  - `#3000`: raises a hard alarm when `A` is missing.
  - `#3006`: optional operator confirmation message.

## Variable usage summary
- Local (#1–#33): `#1` (A).
- Persistent (#500–#999): `#526`, `#527`, `#585`, `#501` (read only).
