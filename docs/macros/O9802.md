# O9802 — Alarm Handler (Retract Then Alarm)

## Purpose
Centralized error handler that logs error information, retracts to `SAFE_Z_MACHINE_IN` **if configured**, and raises a hard alarm. This is the **only macro** allowed to perform a retract-then-alarm sequence.

## Preconditions (Required machine state)
- Spindle state: Any (no spindle commands issued).
- Coolant state: Any (no coolant commands issued).
- Modal requirements (G90/G94/G40/G80 etc.): None required, but this macro **will issue `G53 G0`** if `#526` is set.
- SAFE_Z_MACHINE must be set: **Preferred** (`#526 != 0` enables retract).

## Inputs (Macro arguments)
- `A` = internal error code (stored to `#511`)
- `B` = alarm code for `#3000`
- `C` = context value 1 (reserved, not used in Phase 1)
- `D` = context value 2 (reserved, not used in Phase 1)

## Outputs
- Variables written (local/common/persistent):
  - `#511` LAST_ERROR_CODE
  - `#512` LAST_ALARM_CODE
  - `#585` LAST_STATUS = `-A`
- Offsets written (WCS/tool offsets), if any: None.
- Logs updated (#580–#599): `#511`, `#512`, `#585`.

## Safety checks and failure modes
- If `#526 != 0`, retract to machine Z safe height using `G53 G0 Z[#526]`.
- If `#526 == 0`, **no motion** is performed.
- Always raises `#3000 = B` with a clear message.

## Step-by-step flow (operator/comprehension view)
1) Log `A` and `B` to `#511` and `#512`.
2) Set `#585 = -A`.
3) If `#526` is configured, retract with `G53 G0 Z[#526]`.
4) Raise `#3000 = B` with a clear message.

## G/M code explainer (every code used)
- `G53` : Move in machine coordinate system (non-modal).
- `G0` : Rapid positioning to the safe Z value in machine coordinates.
- System variables used:
  - `#3000`: raises a hard alarm with a numeric code and message.

## Variable usage summary
- Local (#1–#33): `#1` (A), `#2` (B), `#3` (C), `#4` (D).
- Persistent (#500–#999): `#511`, `#512`, `#526`, `#585`.
