# O9800 — Library Init (Defaults Only; No Motion)

## Purpose
Initialize library defaults in persistent variables **only if they are unset (#0)**, validate `UNITS_MODE`, and warn if `SAFE_Z_MACHINE_IN` is not configured. This macro performs **no axis motion** and **uses no M-codes**.

## Preconditions (Required machine state)
- Spindle state: Any (no spindle commands issued).
- Coolant state: Any (no coolant commands issued).
- Modal requirements (G90/G94/G40/G80 etc.): None (no G-codes used).
- SAFE_Z_MACHINE must be set: **No** (macro will warn if unset).

## Inputs (Macro arguments)
None.

## Outputs
- Variables written (local/common/persistent):
  - `#500` LIB_VERSION (default if unset)
  - `#501` LIB_VERBOSE (default if unset)
  - `#510` UNITS_MODE (default if unset)
  - `#530` PROBE_SEEK_FEED (default if unset)
  - `#531` PROBE_RETRACT_FEED (default if unset)
  - `#532` PROBE_MAX_STROKE (default if unset)
  - `#533` TS_MAX_STROKE (default if unset)
  - `#534` MAX_RETRIES (default if unset)
  - `#585` LAST_STATUS (set to `-510`, `-526`, or `1`)
- Offsets written (WCS/tool offsets), if any: None.
- Logs updated (#580–#599): `#585` only.

## Safety checks and failure modes
- If `UNITS_MODE` (`#510`) is not `1` or `2`, the macro **alarms with `#3000`** and sets `#585 = -510`.
- If `SAFE_Z_MACHINE_IN` (`#526`) is `0`, the macro **does not hard fault**; sets `#585 = -526` and (if `#501 != 0`) issues a `#3006` reminder to run O9803.

## Step-by-step flow (operator/comprehension view)
1) Reset `#585` to `0`.
2) Populate defaults **only where variables are unset (#0)**: `#500`, `#501`, `#510`, `#530–#534`.
3) Validate `#510` is `1` or `2`; alarm if invalid.
4) If `#526` is unset, set `#585 = -526` and optionally show a reminder message.
5) If `#526` is set, mark success (`#585 = 1`).

## G/M code explainer (every code used)
- **None.** This macro does not issue G-codes or M-codes.
- System variables used:
  - `#3000`: raises a hard alarm when `UNITS_MODE` is invalid.
  - `#3006`: optional operator message when `SAFE_Z_MACHINE_IN` is unset.

## Variable usage summary
- Local (#1–#33): None.
- Persistent (#500–#999): `#500`, `#501`, `#510`, `#530–#534`, `#585`, `#526` (read only).
