# O9820 — Probe Calibration (Master Ring + Test Bar)

## Purpose
Calibrate the spindle probe’s effective stylus radius and Z trigger length using a master ring and a known-length test bar. This macro computes and stores `#540` (stylus radius) and `#541` (stylus length/trigger offset) using **O9812** for center-find X/Y touches and **O9810** for Z probing. No WCS is written; calibration is performed in machine coordinates.

## Preconditions (Required machine state)
- Spindle state: Oriented with `M19` before each probing sequence (handled inside O9810 and O9812 for G31 strokes).
- Coolant state: Any (no coolant commands issued).
- Modal requirements (G90/G94/G40/G80 etc.): Entry any; macro exits in `G90` and `G94`.
- SAFE_Z_MACHINE must be set: **Yes** (`#526 != 0`).

## Inputs (Macro arguments)
- `A` = mode (1 = inch operator mode). **Required.**
  - If `#510 = 2` (mm), O9820 converts inch inputs to mm.
- `B` = ring nominal **inner diameter** (inches). **Required.**
- `C` = ring center X **machine coordinate**. Optional; `0` triggers center-find via O9812.
- `D` = ring center Y **machine coordinate**. Optional; `0` triggers center-find via O9812.
- `E` = Z reference surface **machine Z** (inches). **Required** for Z calibration.
- `F` = test bar length **L** (inches). **Required** for Z calibration.

## Outputs
- Variables written (local/common/persistent):
  - `#540` STYLUS_RADIUS (effective; units per `#510`)
  - `#541` STYLUS_LENGTH / Z trigger offset (effective; units per `#510`)
- Offsets written (WCS/tool offsets), if any: **None**.
- Logs updated (#580–#599): optional; record last inputs/hits if implemented.

## Safety checks and failure modes
- Skip precheck behavior: **Not implemented in Phase 3** (same constraint as O9810/O9812).
- Bounded stroke behavior:
  - Center-find uses O9812 (bounded by `#532/#533` via O9812).
  - Z probing uses O9810 with `#532` stroke caps.
- Retract behavior:
  - O9812 and O9810 perform `G53 G0 Z[#526]` after each hit; O9820 must not override.
- Alarm codes/messages:
  - If required inputs are missing/zero, fault via O9802 with deterministic codes.
  - If any O9812/O9810 call faults, propagate O9802 alarm and exit cleanly.
  - If `C` or `D` are zero, perform center-find via O9812 (X-/X+/Y-/Y+).

## Step-by-step flow (operator/comprehension view)
1) Verify SAFE_Z is set and ring/test bar are mounted.
2) If C/D are zero, find ring center via O9812 using X-/X+/Y-/Y+ touches.
3) Using ring diameter `B`, compute effective stylus radius from X and Y diameters.
4) Probe Z reference surface with test bar to compute stylus length/trigger offset.
5) Store `#540` and `#541`, log results, and exit with clean modals.

## G/M code explainer (every code used)
- `G65` : Macro call (used to invoke O9812 for center-find strokes and O9810 for Z probing).
- `G90` : Absolute positioning (baseline entry/exit).
- `G91` : Incremental positioning if needed for approach (if used, return to `G90`).
- `G94` : Feed-per-minute mode on exit.
- `G53` : Machine coordinate retracts (performed by O9810).
- `G0` : Rapid positioning for approach/retract (if used).
- `M19` : Spindle orient before each G31 (issued in O9810).
- `M99` : Return from macro.
- System variables used:
  - `#5061/#5062/#5063`: captured skip position (from O9810).

## Variable usage summary
- Local (#1–#33): `#1` (A), `#2` (B), `#3` (C), `#4` (D), `#5` (E), `#6` (F).
- Persistent (#500–#999):
  - `#510` UNITS_MODE (read)
  - `#526` SAFE_Z_MACHINE_IN (read)
  - `#540` STYLUS_RADIUS (write)
  - `#541` STYLUS_LENGTH (write)
  - `#532` PROBE_MAX_STROKE (read)
