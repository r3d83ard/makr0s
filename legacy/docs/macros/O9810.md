# O9810 — Probing Primitive (Single Axis G31)

## Purpose
Perform a single-axis bounded G31 probe move, capture the hit position from `#5061–#5063`, log commissioning data, and retract to machine safe Z. This is the Phase 2 primitive used to validate probing safety, logging, and modal hygiene.

## Preconditions (Required machine state)
- Spindle state: Any (no spindle commands issued).
- Coolant state: Any (no coolant commands issued).
- Modal requirements (G90/G94/G40/G80 etc.): Entry any; **macro exits in `G90` and `G94`**.
- SAFE_Z_MACHINE must be set: **Yes** (`#526 != 0`), otherwise macro faults via O9802.

## Inputs (Macro arguments)
- `A` = axis (`1=X`, `2=Y`, `3=Z`). **Required.**
- `B` = stroke distance (**positive**, current units). **Required.**
- `C` = mode (`1=probe`, `2=toolsetter`). **Required.** Selects max stroke source (`#532` or `#533`).
- `D` = feed (0 = use `#530`, otherwise use `D`). Optional.

## Outputs
- Variables written (local/common/persistent):
  - `#580` LAST_RUN_ID / counter (increment each call)
  - `#581` LAST_INPUT_A (axis)
  - `#582` LAST_INPUT_B (stroke)
  - `#583` LAST_INPUT_C (mode)
  - `#584` LAST_RESULT_2 (hit position value from `#5061/#5062/#5063`, or `0` if no hit)
  - `#585` LAST_STATUS (`1` on success; set by O9802 on fault)
- Offsets written (WCS/tool offsets), if any: None.
- Logs updated (#580–#599): `#580–#585` as above.

## Safety checks and failure modes
- Skip precheck behavior: **Not implemented in Phase 2** (no macro-accessible skip-state method; see `docs/saftey.md`).
- Bounded stroke behavior:
  - Commanded stroke is `MIN(B, #532/#533)` based on mode `C`.
  - If no trigger within max stroke → fault via O9802 (`A/B=921`, message `NO TRIGGER`).
- Retract behavior:
  - If `#526 == 0` → fault via O9802 (`A/B=920`, message `SAFE_Z NOT SET`).
  - Else retract with `G53 G0 Z[#526]`.
- Alarm codes/messages (via O9802):
  - `920` = SAFE_Z NOT SET
  - `921` = NO TRIGGER
  - `922` = SKIP STUCK (**reserved; not used in Phase 2**)

## Step-by-step flow (operator/comprehension view)
1) Validate inputs `A/B/C` and select max stroke from `#532` or `#533`.
2) Log inputs to `#581–#583` and increment `#580`; initialize `#584 = 0`.
3) Capture pre-skip `#506x` value, then execute bounded incremental G31 stroke along the selected axis.
4) Capture post-skip `#506x`; if changed, store hit position to `#584`.
5) If no hit is captured, fault via O9802 with `A/B=921`.
6) Retract to `G53 G0 Z[#526]` (or fault if SAFE_Z is unset).
7) Restore modal state (`G90`, `G94`) and exit.

## G/M code explainer (every code used)
- `G31` : Skip (probe) move that captures hit position into `#5061–#5063`.
- `G91` : Incremental positioning for bounded stroke.
- `G90` : Absolute positioning on exit.
- `G94` : Feed-per-minute mode on exit.
- `G53` : Move in machine coordinate system (non-modal).
- `G0` : Rapid positioning for safe Z retract.
- `G65` : Macro call (used to invoke O9802 for faults).
- `M99` : Return from macro.
- System variables used:
  - `#5061/#5062/#5063`: captured skip position.
  - `#3000`: raised by O9802 for hard alarms.

## Variable usage summary
- Local (#1–#33): `#1` (A), `#2` (B), `#3` (C), `#4` (D).
- Persistent (#500–#999):
  - `#526` SAFE_Z_MACHINE_IN (read)
  - `#527` SAFE_Z_MACHINE_MM (read only; reserved for metric mirror)
  - `#530` PROBE_SEEK_FEED (read)
  - `#531` PROBE_RETRACT_FEED (read; not used in Phase 2 because retract is `G53 G0`)
  - `#532` PROBE_MAX_STROKE (read)
  - `#533` TS_MAX_STROKE (read)
  - `#580–#585` commissioning logs/status (write)
