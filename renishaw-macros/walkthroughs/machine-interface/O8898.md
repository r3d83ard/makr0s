# O8898 - REN INSPECTION START CONFIG

## Purpose
Brief: This macro supports **ren inspection start config** on the Smart Machine Tool MINI using a Fanuc 0i-MF control.

## Machine Context

- Control: Fanuc 0i-MF
- Units/offset behavior depends on active Renishaw settings, current work offset, and active tool length values.
